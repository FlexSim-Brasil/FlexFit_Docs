About RailWorks

RailWorks is a 3rd party module developed and maintained by FlexSim Brazil. It provides faster and more accurate modelling of railroad systems. It is especially useful within the oil, gas, and bulk industry and a powerful solution to the transport of sugar, fertilizers, grain, steel, derivates that come from the main agricultural regions, blades to the wind energy sector. Designed to represent a real environment for the railway problem modeling, with less configuration. Integrated with FlexSim's People Module, users can create accurate representations of subway stations and metro networks. To use this module without restrictions, a RailWorks license is required.

Obtaining and activating the license

The RailWorks license can be obtained and activated in the same way as your FlexSim license or any additional licenses. Please contact FlexSim support or your local distributor for more information on obtaining or activating a license.

As of RailWorks version 21.1.0, RailWorks licenses are versioned according to the same numbering scheme as FlexSim. For instance, if you want to run RailWorks on FlexSim 21.1, you will need license number ending in 21.1 or higher. As long as you have maintenance enabled on your license, it will be automatically upgraded together with all your other licenses as you install or upgrade FlexSim. If your maintenance has expired, your license will not automatically upgrade, and you will only be able to install previous versions of RailWorks which are linked to previous versions of FlexSim. Note, however, that as long as you have a license for version 21.1, you will continue to receive bug fixes for 21.0 (LTS) and 21.1 versions - new features will only be added to later versions though.

Match the first two version numbers

The first two version numbers of RailWorks should always match that of your FlexSim installation. The third RailWorks version number is updated independently of FlexSim releases.

Usually, the third version number usually does not have to match. If a RailWorks release is only compatible with certain FlexSim versions this will be explicitly indicated in the Release Notes and Product Announcements (e.g. "RailWorks xx.yy.zz can only be used with FlexSim xx.yy.ww or higher").

Example: RailWorks version 21.0.3 will work with all releases of FlexSim 21.0 (LTS), unless otherwise specified: you do not have to use it specifically with FlexSim 21.0.3. However, it will not work with any version of FlexSim 2020.

License types

RailWorks runs in standard ('full') mode when you have purchased and activated a license.

Otherwise, it runs in a restricted mode which puts limitations on the number of flow objects in any flow network and the number of flow recalculations. The RailWorks license is independent of your FlexSim license; it is entirely possible, for example, to run a full FlexSim license with an RailWorks Express version or even FlexSim Express with a full RailWorks license.

Only 3D objects will be considered and counted as number of objects. Flowitem will not be counted.
