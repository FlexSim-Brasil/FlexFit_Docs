Collision and Alternative Routes

These tutorials will show you how to set up collision detection and automatic train brakezone tools on the RailWorks library, they will also teach you how to configure alternative and mandatory rail routes.

Tasks Covered

This tutorial will cover the following tasks:

Task 6.1

Train Collision Basics

Create a comprehensive model where you will generate collisions with the default routing system behavior, detect them, and then avoid them using the mandatory rails to generate more comprehensive paths. This tutorial will focus on turning off Brakezone, setting up collision detection, and adding obligatory paths to MoveTrain.

Task 6.2

Alternative Paths on Rails

In this task, you will create an alternative route logic to avoid deadlocks on the model. For this, the Breakzone will be turned on, set up the onPass trigger on RailControlPoints and add alternative rails on the deadlocked Rail.
