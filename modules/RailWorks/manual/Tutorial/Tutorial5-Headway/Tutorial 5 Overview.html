Headway

This tutorial will show you how to incorporate the Headway Simulation System into your rail tracks. The tutorial will simulate in a simplified way all the tools that can be used with the headway simulation, such as: including RailControlPoints to the analyzer, adding and deleting tracks, calculating distances automatically, generating log tables, interactive headway graphs, and more. By the end of this tutorial, you will have a comprehensive understanding of how to create and manage a model using the Headway Simulation System, enabling efficient and accurate rail track analysis.
